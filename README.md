# 蒸馏douyin Skill

> 把 douyin-mcp 和 TikHub 串成一条蒸馏流水线——给一条链接，自动跑完视频转录和评论采集，输出可分析的数据。分析什么、怎么分析，留给用户跟 AI 自己磨合。

## 这是什么

一个轻量级的 Skill 包，把两个独立的 MCP 工具（douyin-mcp 和 TikHub）组合成一条抖音数据采集流水线。

**它解决什么问题**：
- 抖音评论区是当前最有价值的"真实信号"数据源，但抖音不开放公开 API。
- 自己写爬虫会被反爬拦截，维护成本极高。
- 这套流水线用两个开源 MCP 工具绕过了这个限制——填入 API Key 就能跑。

**它不解决什么问题**：
- 不替你判断"什么是有价值的信号"——这是用户和 AI 自己的事。
- 不替你决定"输出什么格式"——蒸馏的目标每次可能都不同。
- 不替你做完所有操作——它只负责数据采集，分析是用户和 AI 对话的过程。

## 快速开始

### 1. 申请两个 API Key

| 服务 | 申请入口 | 用途 |
|------|---------|------|
| DashScope（阿里云） | https://dashscope.console.aliyun.com/overview | 视频语音转文字 |
| TikHub | https://api.tikhub.io | 获取抖音评论区数据 |

两个 API 都有免费额度，新用户足够试用几十次蒸馏。

### 2. 配置 MCP 服务器

在 Agent 的 `mcp.json` 中加入：

```json
{
  "mcpServers": {
    "douyin-mcp": {
      "command": "uvx",
      "args": ["--with", "mcp<2.0", "douyin-mcp-server"],
      "env": { "DASHSCOPE_API_KEY": "你的 Key" }
    },
    "tikhub-douyin-sdk": {
      "command": "python",
      "args": ["路径/tikhub-sdk-mcp/server.py"],
      "env": { "TIKHUB_API_KEY": "你的 Key" }
    }
  }
}
```

### 3. 蒸馏一条视频

把下面的链接发给 Agent：

```
https://v.douyin.com/xxxxx
```

Agent 会自动跑：

```
① 解析视频信息（标题/作者/时长）
② 转录视频文字稿（ASR）
③ 拉取评论区（默认 50 条）
④ 把数据回传给你
⑤ 等你告诉它这次想分析什么
```

## 核心理念

**工具是死的，判断是活的。**

这个 Skill 只做一件事——把数据从抖音搬到你面前。搬完之后怎么用，是用户的事。

有些用户想看情绪分布。有些想挖掘选题缺口。有些想追踪竞品话术。有些想监控某个博主的内容变化。每次蒸馏的目标不一样，分析规则就不一样。

所以这个包里**没有预设的分析规则**。这是有意为之。规则应该是用户和 AI 在对话中磨合出来的，不是从模板里复制的——复制别人的规则就复制了别人的判断，你拿到的不是信号，是二手观点。

如果你需要更完整的元认知框架和信号分级方法论，那是另一份资料的内容——这份只负责把数据搬到你面前。
